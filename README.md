# Tune Native

Экспериментальный клиент Яндекс Музыки с нативным интерфейсом на Rust. Отдельный проект, основной [Tune](https://github.com/tune-music/tune) он не затрагивает.

## Цель

Интерфейс в WebView2 ест много памяти, поэтому интерфейс и часть функций переписываются на Rust. Основа остаётся оригинальной: например, вход через OAuth Яндекса.

## Что уже работает

Прототип: вход по коду на странице Яндекса, поиск треков с обложками, воспроизведение с очередью и перемоткой, громкость.

Память на Windows 11, замер диспетчером процессов. Tune — простой без воспроизведения, Tune Native — со списком из 20 обложек и играющим треком:

| | Процессы | Рабочий набор | Закрытая память |
|---|---|---|---|
| Tune 0.1.5 | 8 | 811 МБ | 487 МБ |
| Tune Native | 1 | 56 МБ | 12 МБ |

Рабочие наборы процессов Tune просто сложены, поэтому общая память в нём посчитана несколько раз. Сравнивать точнее по закрытой памяти.

## Сборка

```bash
cargo run
```

Проверка без окна, после входа: `tune-native --smoke "запрос"`.
