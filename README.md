# Tune Native

Экспериментальный клиент Яндекс Музыки с нативным интерфейсом на Rust. Отдельный проект, основной [Tune](https://github.com/tune-music/tune) он не затрагивает.

## Цель

Интерфейс в WebView2 ест много памяти, поэтому интерфейс и часть функций переписываются на Rust. Основа остаётся оригинальной: например, вход через OAuth Яндекса.

## Что уже работает

Прототип: вход через OAuth Яндекса, как в оригинальном клиенте, «Моя волна» с обратной связью, «Мне нравится» и лайки, поиск треков с обложками, воспроизведение с очередью и перемоткой, громкость.

Память на Windows 11, счётчики процесса Windows. Tune — через 25 секунд после запуска, без воспроизведения. Tune Native — с загруженными обложками, без звука, отрисовка на видеокарте через DirectX 12:

| | Процессы | Закрытая память |
|---|---|---|
| Tune 0.1.5 | 8 | 487 МБ |
| Tune Native | 1 | 140–175 МБ |

На процессоре приложение занимает около 25 МБ, но прокрутка лагает, поэтому основной вариант — видеокарта. Без неё приложение само перейдёт на процессор.

## Сборка

```bash
cargo run
```

Проверка без окна, после входа: `tune-native --smoke "запрос"`.

Окно с готовым разделом, без звука: `tune-native --preview wave`, `likes` или поисковый запрос.

Сырой ответ API для разбора: `tune-native --api путь`.

Проверка лайков и волны: `tune-native --smoke-library "запрос"`. Ставит лайк на найденный трек и сразу снимает его, а волне отправляет событие запуска.
