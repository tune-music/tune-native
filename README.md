# Tune Native

Нативный клиент Яндекс Музыки для Windows на Rust. Интерфейс рисуется видеокартой (DirectX 12 или Vulkan, с автоматическим переходом на процессор при необходимости) в одном процессе.

[Сайт](https://tune-music.github.io/tune/) · [Скачать установщик](https://github.com/tune-music/tune-native/releases/latest)

## Возможности

- **Музыка и медиатека:** главная, «Моя волна» (в том числе «Моя волна на двоих»), «Мне нравится» с полной синхронизацией отметок аккаунта, поиск с обложками, синхронные тексты, клипы и подкасты.
- **Плеер:** воспроизведение с очередью, перемоткой и управлением громкостью.
- **Вход:** авторизация через OAuth Яндекса.
- **Без цензуры:** подмена треков и загрузка версий без цензуры в «Загруженное».
- **Кастомизация:** тема Aquarium с живым фоном и пузырями, Liquid Glass и цвета стандартной темы.
- **Отрисовка:** выбор режима в настройках («Отрисовка»: DirectX 12, Vulkan или процессор).
- **Обновления:** встроенная проверка новых версий в `releases/latest` с проверкой размера и SHA-256 и тихой установкой.

## Установка

Скачайте установщик `Tune-Native-<версия>-setup.exe` из [последнего выпуска](https://github.com/tune-music/tune-native/releases/latest). Ставится для текущего пользователя без прав администратора.

## Сборка и отладка

```bash
cargo run
```

Клипы воспроизводит `libmpv`. Библиотека в репозиторий не входит: скачайте `libmpv-2.dll` из архива `mpv-dev-x86_64-*.7z` сборки [shinchiro/mpv-winbuild-cmake](https://github.com/shinchiro/mpv-winbuild-cmake/releases) и положите в `vendor/mpv/` — при сборке она копируется рядом с программой. Без неё всё остальное работает, а клипы открываются в браузере.

Флаги запуска для проверки и отладки:

- `tune-native --smoke-clip <номер клипа>` — поток, первые кадры и пауза без окна.
- `tune-native --smoke "запрос"` — проверка поиска без окна после входа.
- `tune-native --smoke-library "запрос"` — проверка лайков и волны (ставит и снимает лайк, отправляет событие запуска волны).
- `tune-native --preview wave` (`likes` или поисковый запрос) — окно с готовым разделом без звука.
- `tune-native --api путь` — сырой ответ API для разбора.

## Установщик и релиз

```powershell
pwsh -File installer/build.ps1
```

Собирает программу и NSIS-установщик `target/installer/Tune-Native-<версия>-setup.exe` (для текущего пользователя, без прав администратора). Нужен `makensis.exe`: по умолчанию берётся из `%LOCALAPPDATA%\tauri\NSIS` или по пути из переменной `MAKENSIS`.

Перед сборкой добавьте раздел новой версии в `CHANGES.md` — из него Tune Native показывает окно «Что нового». Релиз публикуется под тегом `v<версия>` с установщиком во вложениях (обновление ставится тихо с ключами `/S /R`).
